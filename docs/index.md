# Data Analytics Project Repo

Welcome to the documentation for this data analytics project.

This site serves as a central hub for understanding the project's structure, development workflows, and key business definitions. The goal is to ensure our work is **reproducible**, **reviewable**, and **easy for new team members to onboard**.

Use the navigation menu to explore different sections:

*   **Getting Started:** How to set up and run the project.

*   **Repository Structure:** A detailed map of all files and folders.

*   **Pipelines:** An explanation of the automated workflows.

*   **Guides:** Conventions for SQL, notebooks, and testing.

*   **References:** The project's data dictionary and metric definitions.
